# Crypto Market Data Pipeline

## What this project does

A Python-based data ingestion pipeline that fetches cryptocurrency price data from external APIs and stores structured datasets for analysis.

## Tech Stack

Python, REST APIs, CSV, Logging

## How it works (high level)

- Fetches market data from an external API
- Stores raw data
- Transforms raw JSON into structured CSV files
- Logs pipeline execution and errors
